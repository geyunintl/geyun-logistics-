# 歌运物流官网高级素材包

## 使用原则
- 真实照片用于“服务网络 / 关于歌运 / 仓储实力”模块，增强信任感。
- 暗色版图片用于首屏、分公司详情页背景，前端叠加文字会更高级。
- 干净版图片用于卡片、照片墙、图库。
- SVG 图形用于炫酷动效背景，建议前端配合 GSAP / Framer Motion / Three.js 做发光航线与粒子动画。
- 文字和核心卖点建议在前端 HTML 中渲染，不要直接写死到图片里，方便 SEO 和后续改文案。

## 文件夹说明
- `01_branch_photos_refined/`：分公司照片精修干净版。
- `02_branch_photos_dark_overlay/`：分公司照片暗色科技版。
- `03_video_frames_refined/`：视频抽帧精修版。
- `04_hero_backgrounds/`：视频抽帧暗色英雄图。
- `05_web_graphics_svg/`：全球航线、数据驾驶舱、渠道卡片背景 SVG。
- `06_data_for_codex/`：可直接给前端使用的站点数据 JSON。
