🤖 GPT 小助手

粘贴 ChatGPT 的 session JSON（含 accessToken / sessionToken），即可转 Cookie 登录、查订阅、生成各套餐支付链接。

Session JSON / Token

查订阅/生成支付链接用 accessToken；转 Cookie 用 sessionToken。直接粘整段 session JSON 即可，自动识别。

① Session 转 Cookie

把 sessionToken 转成可导入浏览器的登录态 Cookie（Cookie-Editor 格式）。

② 查询订阅 / 取消续费

查询账号当前订阅（套餐/到期/续费/座位/欠费），并可一键取消自动续费（权益保留到到期日，到期后不再扣款）。

③ 生成支付链接

用上面的 accessToken 生成指定套餐的官方 hosted checkout 长链接，点开直接付款升级。

④ F12 跳转脚本

无需提交 session。生成一段 JS，让用户在自己已登录的 ChatGPT 控制台运行，用其自身登录态生成支付页并自动跳转（更安全）。套餐/国家/货币沿用上面 ③ 的选择。

用法：复制后，让用户在已登录的 chatgpt.com 标签页按 F12 → Console 粘贴回车，会自动跳到对应套餐支付页。
